# 苏轼：黄州·赤壁

一个可玩的浏览器原型：第三人称走在黄州江岸，读四处落点——东坡雪堂、赤壁矶头、《赤壁赋》夜游、书法与画意。读完解锁短结局，并预告后续站点。

画面是程序生成的低多边形夜色，不使用付费素材。文字按通行的通俗史来写：乌台诗案后的贬谪、东坡得名、文赤壁与前后《赤壁赋》、《黄州寒食诗帖》。

## 本地运行

需要 Node.js 20 以上。

```bash
npm install
npm run dev
```

开发服务器默认在 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

生产构建：

```bash
npm run build
npm run preview
```

`npm run build` 会先做类型检查，再输出到 `dist/`。

界面字体是马善政楷书和思源宋体简体，经 `@fontsource` 引入，许可为 SIL Open Font License。

## 操作

| 动作 | 桌面 | 触屏 |
| --- | --- | --- |
| 移动 | `W` `A` `S` `D`，或方向键上下 | 左下摇杆 |
| 转头 | 按住鼠标拖拽；`←` `→` 或 `Q` | 在画面上滑动 |
| 走到某处 | 单击地面 | 轻点地面 |
| 快走 / 轻跳 | `Shift` / `空格` | — |
| 阅读 | 靠近光柱后按 `E` 或 `Enter` | 点「阅读」 |
| 关掉文牍 | 「继续」、`Esc` 或 `Enter` | 「继续」 |
| 重读 | 点右上已点亮的足迹 | 同左 |
| 回到岸上 | 右下角按钮；掉进江里也会送回 | 同左 |

进关后，画面上方会提示最近一处还没读的落点在哪个方向。

## 这一关里有什么

1. 题记：贬谪黄州，以及「东坡」这个号从何而来。
2. 东坡雪堂：马正卿请地、耕种、雪中成堂。
3. 赤壁矶头：《念奴娇·赤壁怀古》，以及「人道是」。
4. 夜游：前、后《赤壁赋》。
5. 墨迹与竹石：《黄州寒食诗帖》、胸有成竹、枯木竹石。
6. 四处都读过之后，出现结局卡，预告眉山 → 汴京 → 惠州 · 儋州。

## 以后怎么加关

现在只有一个场景。下一站可以做成同一套结构，不必先做整张人生地图。

- 文案继续放在 `src/content/story.ts`。每处热点有 `id`、站立点 `position`、短名、两三节正文和一句出处清楚的引文。
- 地形、碰撞和布景在 `src/game/Level.tsx` 与 `src/game/Scenery.tsx`。可行走的盒子同时是碰撞体和点击落点。
- 人物移动在 `src/game/Player.tsx`（Rapier 运动学角色控制器）。镜头在 `src/game/CameraRig.tsx`。
- 界面在 `src/ui/Overlay.tsx`。结局列表 `STATIONS` 只是预告，点了不会切关。

建议的后续站点，仍然一关一景：

1. **眉山**：纱縠行、家学、苏洵与苏辙。少写传说，多写「一门父子」怎么读书。
2. **汴京**：嘉祐二年进士，以及元丰二年的乌台诗案。狱中一段宜短、宜克制，不做成闯关。
3. **惠州 · 儋州**：白鹤峰、朝云；桄榔庵与载酒堂。岭南不是惩罚展览，重点仍是日常生活和诗文。

杭州西湖、密州、徐州可以以后再插，不挡这条主线。换关时保留现在的循环即可：走到、按 E、读完、集齐、一张结尾卡。
